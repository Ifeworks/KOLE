Design and build a complete **mobile-first application called “KÓLẸ̀”** for on-demand waste collection in Osogbo, Osun State, Nigeria.

IMPORTANT:

* This is a **mobile application**, NOT a traditional website.
* Design it primarily for smartphone screens.
* The experience should feel like a polished Nigerian fintech/utility app.
* Use **OPay as inspiration for usability, information hierarchy, cards, wallet/payment screens, transaction history, bottom navigation, and clear CTAs**, but DO NOT copy OPay's branding, logo, colors, or exact UI.
* KóLẹ̀ should have its own distinct visual identity based around **cleanliness, trust, sanitation, reliability, and technology**.
* The app must feel production-ready and realistic, not like a generic UI concept.
* Use realistic Nigerian names, Nigerian phone-number formats, ₦ currency, Osogbo locations, and realistic waste-collection scenarios.

## BRAND

App name: **KÓLẸ̀**

Tagline:
**“**Smart pickup. Zero hassle**.”**

Primary market:
**Osogbo, Osun State, Nigeria**

Core service:
On-demand waste pickup connecting households with verified independent waste collectors.

Pricing:
**₦1,500 per SOS pickup**

Platform commission:
**15% = ₦225**

Collector payout:
**₦1,275 per completed pickup**
